The Build

One rebuild, two structures, one panel system.

The main residence and ADU share the same 4C SAFE™ system, so both structures carry the same fire-resistant, factory-built construction and move through permitting and installation together.

One coordinated rebuild

The main residence and ADU are designed, permitted, and built as a single scope, so the property doesn't need a second disruptive construction phase later.

Fire-resistant from the frame out

Steel framing rated 1-HR and 2-HR fire-resistive gives this rebuild a fundamentally different fire-risk profile than the home it replaces.

Reviewed and ready

The design has already been reviewed by Los Angeles County, giving this rebuild a clear starting point instead of beginning the design process from scratch.
